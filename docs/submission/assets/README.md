That check's source commit and response evidence are preserved in `docs/live/normal-use.json`. These screenshots are recorded evidence, not a newly running public live service. Test totals correspond to the verified software commit identified in the presentation metadata.

The [separate product-demo walkthrough](../../demo/prototype.webm) remains a 2:18 recording using visibly fictional examples. Its recording metadata and actual production verification are distinct. The presentation does not turn that fictional walkthrough into real-data evidence.
