# EventScope prototype demonstration

These materials show the working local research application using **fictional examples**, not authenticated production data. Live verification and platform entries have separate gates in [delivery status](../submission/status.json).

- [Desktop workspace](desktop.png)
- [Comparison and evidence capture](evidence.png)
- [390px mobile research view](mobile.png)
- [Recorded English prototype walkthrough](prototype.webm) — 2 minutes 18 seconds, with captions and no audio
- [Example JSON capture](example-brief.json), [Markdown](example-brief.md), [CSV](example-brief.csv)

The example files were downloaded through the actual app's export buttons. They preserve the captured source mode, timestamps and limits. CSV is quoted and protected against formula prefixes; apostrophes may be present to keep spreadsheet values as text.

[Recording metadata](recording.json) describes the actual screen walkthrough. The [video check](video-check.json) records duration, dimensions and sampled frames; the [visual check](visual-check.json) records mobile width and page errors. English captions are presentation overlays and do not claim to be an application feature. The prototype does not invent a ten-minute baseline for its initial samples. No user, revenue, production-read or completed-submission claim is made.
